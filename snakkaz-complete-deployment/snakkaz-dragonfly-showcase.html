✨ Øyestikker Features

🧠 Calm Technology Prinsipper:

  • Natural Movement - Svever som en ekte øyestikker
  • Subtle Feedback - Reagerer på interaksjon uten å distrahere
  • Accessibility First - Keyboard navigation og high contrast
  • Performance Optimized - CSS animations, ikke JavaScript

🎨 Design Prinsipper:

  • Forenklet Fargepalett - 4 hovedfarger (ikke 6+)
  • Liquid Glass - Transparent og moderne
  • Responsive - Fungerer på alle skjermstørrelser
  • Contextual - Forskjellige varianter for ulike situasjoner
