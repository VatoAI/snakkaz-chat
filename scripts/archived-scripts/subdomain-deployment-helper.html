🛠️ Deployment Instructions

  1. Access your hosting control panel (cPanel, Plesk, or similar)
  2. Open File Manager and navigate to the subdomain directories
  3. For each subdomain:
    • Delete all existing files in the directory (keep cgi-bin if present)
    • Upload the corresponding ZIP file
    • Extract the ZIP file
    • Move all files from the extracted folder to the subdomain root
    • Ensure .htaccess file is present and visible
