## 🔧 Technical Architecture

### Frontend (React/TypeScript)
- **Framework:** React 18.3.1 + TypeScript
- **Routing:** React Router DOM 6.30.0 
- **Styling:** TailwindCSS + Custom CSS (snakkaz-beta-unified-design.css)
- **State Management:** Zustand + React Query patterns
- **Build Tool:** Vite (optimized for production)

### Backend Integration
- **Database:** Supabase (PostgreSQL)
- **Auth:** Supabase Auth + Custom JWT
- **Real-time:** Supabase Realtime + WebRTC
- **MCP Server:** Express.js på port 3001 (local dev)
- **Security:** Helmet, CORS, Rate limiting
