# SnakkaZ Chat - Fresh Start 2025 🚀

## Hva vi skal lage

En modern, sikker norsk chat-app med:

- **Norsk eleganse** - Apple-inspirert design
- **End-to-end kryptering** - Signal-nivå sikkerhet
- **Modern React/TypeScript** - Beste praksis
- **Glass morphism** - Premium visuell design
- **21st.dev Magic MCP** - AI-powered UI generering

## Design-prompt for 21st.dev Magic MCP:

**Design Vision:**
Lag en ultra-moderne norsk chat-applikasjon inspirert av Apple's design-språk og Signal's sikkerhet.

**Key Features:**

1. **Norwegian Premium Design** - Elegant, minimalistisk, high-end
2. **Security First** - Synlige krypterings-indikatorer
3. **Glass Morphism** - Backdrop blur, transparens, dybde
4. **Aurora Bakgrunn** - Subtile color-gradients (blå/lilla/grønn)
5. **SnakkaZ Branding** - Norge flagg, premium badges

**Color Palette:**

- Primary: #007AFF (SnakkaZ Blue)
- Secondary: #5856D6 (SnakkaZ Purple)
- Success: #34C759 (Security Green)
- Warning: #FF9500 (Alert Orange)
- Error: #FF3B30 (Critical Red)

**Components å lage:**

1. Chat interface med kontakt-liste
2. Message bubbles med status
3. Input-felt med krypterings-indikatorer
4. Header med SnakkaZ logo
5. Security badges og online-status

**Tekst:** Alle tekster på norsk
**Mood:** Premium, trygg, moderne, norsk eleganse
