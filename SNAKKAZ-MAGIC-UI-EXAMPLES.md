# SnakkaZ Magic UI Eksempler 🎨✨

Disse kommandoene kan brukes med 21st.dev Magic MCP for å generere SnakkaZ-komponenter:

## 🗨️ Chat Komponenter

### Meldingsboble

```
/ui Lag en SnakkaZ meldingsboble med liquid glass effect, aurora bakgrunn, krypteringsikon og norsk eleganse. Bruk rgba(255,255,255,0.1) bakgrunn, 16px border-radius, og backdrop-filter blur(20px).
```

### Chat Input

```
/ui Design en chat input-felt for SnakkaZ med glass morphism, SnakkaZ blue focus state (#007AFF), og placeholder text på norsk. Inkluder send-knapp med aurora gradient.
```

### Chat Header

```
/ui Opprett en chat header for SnakkaZ med brukerinfo, krypteringsstatus ikon, liquid glass bakgrunn og premium norsk design. Bruk SF Pro Display font.
```

## 🔐 Auth Komponenter

### Login Form

```
/ui Lag en SnakkaZ login form med aurora gradient bakgrunn, liquid glass cards, norsk flagg subtilt integrert, og "Sikker pålogging" heading. Bruk SnakkaZ fargepalett.
```

### Registration Card

```
/ui Design en registrerings-card for SnakkaZ med glass morphism, sikkerhetsfokus, end-to-end kryptering badge, og elegant norsk typografi. Inkluder validering med SnakkaZ green (#34C759).
```

## 🚀 Navigation & Layout

### Sidebar Navigation

```
/ui Opprett en sidebar for SnakkaZ med liquid glass effect, chat room liste, MCP status indikator, admin-modus toggle og norsk navigation labels. Bruk backdrop-filter blur(40px).
```

### Tab Navigation

```
/ui Lag tab navigation for SnakkaZ med glass morphism, active state i SnakkaZ blue, smooth transitions og mobile-optimized touch targets (minimum 44px).
```

## 🎨 Special Effects

### Glass Card Container

---

**Tips for beste resultater:**

- Nevn alltid "SnakkaZ" for brand konsistens
- Spesifiser liquid glass/glass morphism effects
- Inkluder norske labels der passende
- Bruk SnakkaZ fargepalett (#007AFF, #5856D6, etc.)
- Spesifiser backdrop-filter og rgba verdier
- Fokuser på sikkerhet og premium følelse

**Eksempel kommando:**
`/ui Lag en SnakkaZ chat message bubble med liquid glass bakgrunn rgba(255,255,255,0.1), 16px border radius, kryptering ikon i grønt, og norsk tekst styling`
