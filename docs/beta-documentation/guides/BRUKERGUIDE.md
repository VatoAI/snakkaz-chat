# 📱 SnakkaZ - Komplett Brukerguide

*Velkommen til SnakkaZ - Norges sikreste chat-app med ende-til-ende-kryptering*

## 🚀 Kom i gang med SnakkaZ

### Systemkrav
- **Nettleser:** Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Operativsystem:** Windows 10+, macOS 10.15+, Linux Ubuntu 18.04+
- **Internett:** Stabil bredbåndsforbindelse (2 Mbps anbefalt)
- **Lagring:** Minimum 50 MB ledig plass

### Første gangs oppsett

#### 1. Opprett konto
1. Gå til [www.snakkaz.com](https://www.snakkaz.com)
2. Klikk "Registrer deg"
3. Fyll inn:
   - **E-postadresse:** Din gyldige e-post
   - **Passord:** Minimum 8 tegn, inkluder store/små bokstaver og tall
   - **Bekreft passord:** Gjenta passordet
4. Godta våre bruksvilkår og personvernerklæring
5. Klikk "Opprett konto"

#### 2. Bekreft e-post
1. Sjekk din innboks for bekreftelse-e-post
2. Klikk på bekreftelses-lenken
3. Du blir automatisk logget inn

#### 3. Sett opp profil
1. Klikk på profilbildet (øverst til høyre)
2. Velg "Rediger profil"
3. Legg til:
   - **Visningsnavn:** Hvordan andre ser deg
   - **Statusmelding:** Valgfri personlig beskrivelse
   - **Profilbilde:** Last opp et bilde (max 5 MB)

## 💬 Sende meldinger og filer

### Direktemeldinger

#### Start ny samtale
1. Klikk "Ny samtale" (+-ikon)
2. Søk etter kontakt ved e-post eller navn
3. Velg kontakt fra søkeresultatene
4. Begynn å skrive melding

#### Sende tekstmeldinger
1. Skriv melding i tekstfeltet nederst
2. Bruk **Shift+Enter** for ny linje
3. Trykk **Enter** eller klikk send-knappen
4. Melding krypteres automatisk

#### Sende filer
1. Klikk på �� (binders)-ikonet
2. Velg fil fra datamaskinen din
3. Støttede formater: Bilder, dokumenter, videoer, lydfiler
4. Maksimal filstørrelse: 50 MB (beta-versjon)
5. Klikk "Send fil"

### Gruppechatter

#### Opprett gruppe
1. Klikk "Ny gruppe" i menyen
2. Legg til gruppenavn
3. Skriv gruppebeskrivelse (valgfritt)
4. Legg til medlemmer:
   - Søk etter kontakter
   - Velg fra kontaktliste
   - Send invitasjoner via e-post
5. Klikk "Opprett gruppe"

#### Administrere gruppe
**For gruppeadministratorer:**
- **Legg til medlemmer:** Klikk gruppeinfo → "Legg til medlemmer"
- **Fjern medlemmer:** Gruppeinfo → Velg medlem → "Fjern fra gruppe"
- **Gjør til admin:** Medlemsliste → Velg medlem → "Gjør til administrator"
- **Endre gruppenavn:** Gruppeinfo → "Rediger navn"
- **Slett gruppe:** Gruppeinfo → "Slett gruppe" (kun eier)

## 🛡️ Personvern og sikkerhet

### Ende-til-ende-kryptering

#### Hva er E2EE?
- Alle meldinger krypteres på din enhet
- Kun du og mottaker kan lese meldingene
- SnakkaZ kan ikke lese dine meldinger
- Bruker AES-256 kryptering (militær standard)

#### Verifiser sikkerhet
1. Åpne samtale med kontakt
2. Klikk på kontaktnavnet øverst
3. Velg "Sikkerhetsinfo"
4. Sammenlign sikkerhetskoder i person eller per telefon

### Personverninnstillinger

#### Hvem kan kontakte deg
1. Gå til Innstillinger → Personvern
2. Velg "Hvem kan sende meldinger":
   - **Alle:** Alle SnakkaZ-brukere
   - **Kontakter:** Kun godkjente kontakter
   - **Ingen:** Kun du kan starte samtaler

#### Blokkere brukere
1. Åpne samtale med uønsket bruker
2. Klikk på brukernavnet øverst
3. Velg "Blokker bruker"
4. Bekreft blokkering

## ⚙️ Innstillinger og tilpasning

### Utseende

#### Tema
1. Gå til Innstillinger → Utseende
2. Velg tema:
   - **Lys:** Hvit bakgrunn, sort tekst
   - **Mørk:** Sort bakgrunn, hvit tekst
   - **Automatisk:** Følger systeminnstillingen

### Varsler

#### Push-varsler
1. Innstillinger → Varsler
2. Aktiver/deaktiver varsler for:
   - Nye meldinger
   - Gruppeaktivitet
   - Innkommende samtaler

### Språk
1. Innstillinger → Språk
2. Velg "Norsk (bokmål)" for norsk grensesnitt

## 🔧 Feilsøking

### Vanlige problemer

#### "Kan ikke koble til serveren"
**Løsning:**
1. Sjekk internettforbindelsen
2. Oppdater nettleseren
3. Deaktiver VPN midlertidig
4. Prøv å logge ut og inn igjen

#### "Meldinger blir ikke sendt"
**Løsning:**
1. Sjekk internettforbindelsen
2. Vent 30 sekunder og prøv igjen
3. Oppdater siden (F5)
4. Sjekk om mottaker har blokkert deg
