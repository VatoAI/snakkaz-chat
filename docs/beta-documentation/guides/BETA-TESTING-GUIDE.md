# 🧪 SnakkaZ Beta Testing Guide

*Takk for at du deltar i SnakkaZ beta-testing! Din tilbakemelding er uvurderlig for å gjøre SnakkaZ til Norges beste chat-app.*

## 🎯 Hva tester vi?

### Kritiske områder for testing
1. **Sikkerhet og kryptering**
   - Verifiser at meldinger krypteres
   - Test blokkering og rapportering
   - Sjekk personverninnstillinger

2. **Chat-funksjoner**
   - Send tekst, bilder og filer
   - Test gruppechatter
   - Prøv sletting av meldinger

3. **Tale- og videosamtaler**
   - Direktesamtaler
   - Gruppesamtaler
   - Kvalitet og stabilitet

4. **Brukeropplevelse**
   - Navigasjon og brukervennlighet
   - Norsk språkstøtte
   - Responsivitet på forskjellige skjermstørrelser

5. **Ytelse**
   - Lastehastighet
   - Batteridrain (på mobile enheter)
   - Nettverkseffektivitet

## 📋 Beta-testing oppgaver

### Uke 1: Grunnleggende testing
**Oppgaver:**
- [ ] Opprett konto og sett opp profil
- [ ] Send 10 tekstmeldinger til en annen beta-tester
- [ ] Del 3 forskjellige filtyper (bilde, dokument, video)
- [ ] Opprett en gruppechat med 3+ medlemmer
- [ ] Test en 5-minutters talesamtale
- [ ] Prøv en 2-minutters videosamtale

**Dokumenter:**
- Hvor lang tid tok hver oppgave?
- Oppstod det problemer?
- Hvor intuitivt var grensesnittet?

### Uke 2: Avansert testing
**Oppgaver:**
- [ ] Test alle personverninnstillinger
- [ ] Prøv automatisk meldingssletting
- [ ] Blokkér og avblokkér en bruker
- [ ] Eksporter dine data (GDPR-test)
- [ ] Test på forskjellige nettlesere
- [ ] Prøv gruppevideosamtale med 5+ deltakere

**Fokusområder:**
- Fungerer alle sikkerhetsfunksjoner?
- Er ytelsen stabil ved høy bruk?
- Hvordan er batteridrain?

### Uke 3: Stress-testing
**Oppgaver:**
- [ ] Send 100+ meldinger på en dag
- [ ] Upload filer på maksimal størrelse (50 MB)
- [ ] Ha 3+ samtaler åpne samtidig
- [ ] Test under dårlige nettverksforhold
- [ ] Prøv å "krash" appen med ekstrem bruk

**Mål:**
- Finne ytelsesgrenser
- Oppdage edge cases
- Teste stabilitet

## 🐛 Hvordan rapportere feil

### Kritiske feil (løses innen 24 timer)
- **Sikkerhetsproblemer:** Meldinger ikke kryptert, data lekkasje
- **App krasjer:** Total systemfeil
- **Kan ikke logge inn:** Blokkering av grunnleggende funksjon

**Rapporter til:** critical@snakkaz.com

### Vanlige feil (løses innen 3-7 dager)
- **Funksjonsfeil:** Knapper som ikke virker, feil meldinger
- **Ytelsesproblemer:** Langsom lasting, høy CPU-bruk
- **UI-problemer:** Tekst som ikke vises riktig, layout-feil

**Rapporter via:** Appen (Hjelp → Rapporter feil)

### Feilrapport-mal
```
**Problem:**
[Beskriv hva som gikk galt]

**Forventet resultat:**
[Hva skulle ha skjedd]

**Faktisk resultat:**
[Hva som faktisk skjedde]

**Reprodusere:**

3. [Steg 3]

**System:**
- Nettleser: [Chrome 91.0, Firefox 89.0, etc.]
- OS: [Windows 11, macOS 12, Ubuntu 20.04]
- Skjermoppløsning: [1920x1080]

**Skjermbilder:**
[Legg ved bilder hvis relevant]

**Alvorlighetsgrad:**
[Kritisk / Høy / Medium / Lav]
```

## 💡 Feedback-kategorier

### Forbedringsforslag
- **Nye funksjoner:** Hva savner du?
- **UI/UX forbedringer:** Hvordan kan vi gjøre det bedre?
- **Tilgjengelighetsforbedringer:** For brukere med spesielle behov

### Positive tilbakemeldinger
- **Hva fungerer bra?** Hjelper oss å prioritere
- **Favoritfunksjoner:** Hvilke funksjoner liker du best?
- **Sammenligning:** Hvordan er SnakkaZ vs andre apper?

### Norsk-spesifikk feedback
- **Språkbruk:** Er norsk terminologi naturlig?
- **Kulturell relevans:** Passer appen norske bruksmønstre?
- **Lokale funksjoner:** Trenger vi Norge-spesifikke funksjoner?

## 🏆 Beta-tester program

### Beta-tester nivåer

#### Bronse Beta-tester
**Krav:** 5+ feilrapporter eller forslag
**Fordeler:**
- Tidlig tilgang til nye funksjoner
- Beta-tester badge i profil
- Direkte kontakt med utviklingsteam

#### Sølv Beta-tester  
**Krav:** 15+ kvalitets-rapporter
**Fordeler:**
- Alt fra Bronse
- Gratis premium når SnakkaZ lanseres
- Invitasjon til beta-tester events

#### Gull Beta-tester
**Krav:** 30+ rapporter + betydelig bidrag
**Fordeler:**
- Alt fra Sølv
- Permanent gratis premium-konto
- Medbestemmelse i produktutvikling
- Spesiell anerkjennelse i appen

### Belønninger
- **Beste månedlige rapport:** 1000 NOK gave-kort
- **Mest kritiske funn:** 2000 NOK gave-kort  
- **Best forslag implementert:** 5000 NOK gave-kort

## 📊 Testing metrikker

### Hva vi måler
- **Responstid:** Hvor raskt laster appen?
- **Feilrate:** Hvor ofte oppstår problemer?
- **Brukertilfredshet:** Net Promoter Score (NPS)
- **Funksjonsadopsjon:** Hvilke funksjoner brukes mest?

### Dine bidrag
- **Antall rapporter:** Kvantitet og kvalitet
- **Testing timer:** Tid brukt på testing
- **Funnet unike feil:** Feil ingen andre har rapportert
- **Forslag implementert:** Hvor mange av dine ideer brukes
