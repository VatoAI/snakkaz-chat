# ❓ SnakkaZ - Ofte stilte spørsmål (FAQ)

## �� Sikkerhet og personvern

### Er SnakkaZ virkelig sikkert?
**Ja!** SnakkaZ bruker ende-til-ende-kryptering (E2EE) med AES-256 standard. Dette betyr:
- Kun du og mottakeren kan lese meldingene
- SnakkaZ kan ikke lese dine meldinger
- Meldinger krypteres på din enhet før sending
- Samme sikkerhetsnivå som banker bruker

### Kan SnakkaZ lese mine meldinger?
**Nei.** Vi bruker ende-til-ende-kryptering som gjør det teknisk umulig for oss å lese dine meldinger. Selv om noen hacket våre servere, ville de kun finne krypterte data som er uleselig uten dine private nøkler.

### Hvor lagres mine data?
- **Meldinger:** Kryptert på sikre servere i Europa (GDPR-område)
- **Profil:** Minimal informasjon (e-post, navn) lagret sikkert
- **Filer:** Kryptert før opplasting, lagret i sikker cloud
- **Nøkler:** Kun på din enhet, aldri sendt til servere

### Følger SnakkaZ norsk personvernlovgivning?
**Ja!** Vi er fullt kompatible med:
- GDPR (Personvernforordningen)
- Norsk personvernlov
- Datatilsynets retningslinjer

## 💬 Bruk av appen

### Hvordan starter jeg en samtale?
1. Klikk "Ny samtale" (+-ikonet)
2. Søk etter person ved e-post eller navn
3. Velg personen fra søkeresultatene
4. Begynn å skrive!

### Kan jeg sende filer?
**Ja!** Du kan sende:
- Bilder (alle formater)
- Dokumenter (PDF, Word, Excel, etc.)
- Videoer (alle formater)
- Lydklipp og musikk
- Maksimal størrelse: 50 MB (beta-versjon)

### Hvordan lager jeg en gruppesamtale?
1. Klikk "Ny gruppe" i menyen
2. Gi gruppen et navn
3. Legg til medlemmer ved å søke etter dem
4. Klikk "Opprett gruppe"

### Kan jeg ha videosamtaler med flere personer?
**Ja!** SnakkaZ støtter gruppevideosamtaler med opptil 100 deltakere samtidig.

## �� Tekniske problemer

### SnakkaZ laster ikke inn
**Prøv dette:**
1. Oppdater nettleseren til nyeste versjon
2. Slå av adblocker midlertidig
3. Sjekk internettforbindelsen
4. Prøv i inkognitomodus/privat surfing

### Jeg kan ikke sende meldinger
**Mulige løsninger:**
1. Sjekk internettforbindelsen
2. Vent 30 sekunder og prøv igjen
3. Oppdater siden (F5)
4. Sjekk om mottaker har blokkert deg
5. Logg ut og inn igjen

### Lydproblemer i samtaler
**For å fikse lyd:**
1. Sjekk høyttalerinnstillinger i nettleser
2. Tillat SnakkaZ tilgang til mikrofon og høyttaler
3. Prøv å dempe og aktivere mikrofon
4. Bruk hodetelefoner for bedre kvalitet
5. Lukk andre apper som bruker lyd

### Videoproblemer
**For å fikse video:**
1. Tillat SnakkaZ tilgang til kamera
2. Lukk andre apper som bruker kameraet (Zoom, Teams, etc.)
3. Sjekk kamerainnstillinger i nettleser
4. Oppdater kameradrivere
5. Prøv å skru kamera av og på igjen

### Appen er treg
**For bedre ytelse:**
1. Lukk andre nettleserfaner
2. Stopp andre videosamtaler/strømming
3. Bruk kabel-internett i stedet for WiFi
4. Start nettleseren på nytt
5. Oppdater til nyeste nettleserversjon

## 📱 Konto og innstillinger

### Hvordan endrer jeg passord?
1. Gå til Innstillinger → Konto
2. Klikk "Endre passord"
3. Skriv inn gammelt passord
4. Skriv inn nytt passord (minimum 8 tegn)
5. Bekreft nytt passord

### Kan jeg bruke SnakkaZ på flere enheter?
**Ja!** Du kan logge inn på:
- Opptil 2 enheter samtidig (beta-versjon)
- Datamaskiner, nettbrett og telefoner
- Meldinger synkroniseres automatisk

### Hvordan sletter jeg kontoen min?
1. Gå til Innstillinger → Konto
2. Klikk "Slett konto"
3. Bekreft ved å skrive inn passordet ditt
4. Klikk "Bekreft sletting"

**Viktig:** Dette sletter all data permanent og kan ikke angres!

### Kan jeg eksportere mine data?
**Ja!** I henhold til GDPR:
1. Gå til Innstillinger → Personvern
2. Klikk "Eksporter mine data"
3. Du får en e-post med nedlastingslenke
4. Data leveres i JSON-format
