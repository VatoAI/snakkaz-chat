🔐 1. ENDE-TIL-ENDE KRYPTERING (E2EE) IMPLEMENTASJON
================================================================================

FILER OPPRETTET/ENDRET:
📁 src/utils/crypto/e2ee.ts (645 linjer)
   - Komplett E2EE-system basert på Web Crypto API
   - AES-GCM 256-bit kryptering med unike IV-er
   - Peer-to-peer kryptering for direktemeldinger
   - Gruppekryptering med nøkkeldistribusjon
   - Secure key caching og performance optimalisering

NØKKELFUNKSJONER IMPLEMENTERT:
   - generateKey(userId, peerId): Generer krypteringsnøkler basert på bruker-ID
   - encryptMessage(message, userId, peerId): Krypter meldinger mellom to brukere
   - decryptMessage(encryptedContent, userId, peerId): Dekrypter meldinger
   - getGroupKey(groupId): Håndter gruppekrypteringsnøkler
   - encryptGroupMessage(message, groupId): Krypter gruppemeldinger
   - decryptGroupMessage(encryptedMessage, groupId): Dekrypter gruppemeldinger
   - exportGroupKey(groupId): Eksporter nøkkel for deling
   - importGroupKey(groupId, exportedKey): Importer delt gruppekrypteringsnøkkel
   - Comprehensive test utilities for validering

SIKKERHETSFUNKSJONER:
   - Unike tilfeldig genererte initialiserings-vektorer (IV) per melding
   - SHA-256 hash for nøkkelderivasjon
   - Sikker nøkkel-caching med automatic cleanup
   - Group key distribution system
   - Tamper-proof message integrity checking
